# ZANECO Appointments System - Quick Reference

## System Summary

| Item | Detail |
|------|--------|
| **Project** | Consumer Appointment Scheduling System |
| **Client** | ZANECO (Zamboanga del Norte Electric Cooperative) |
| **Purpose** | Online scheduling for billing/account concerns across 5 offices |
| **Offices** | Main Office + ASO 1-4 |
| **Concern Types** | Bill Clarification, Account Concern |
| **Appointment Duration** | 30 minutes |
| **Office Hours** | Mon-Fri, 8:00 AM - 5:00 PM |
| **Booking Window** | Up to 30 days in advance |
| **Statuses** | Pending → Confirmed → (Completed / Cancelled / No-Show) |

## Database Tables (7)

| Table | Purpose |
|-------|---------|
| `offices` | 5 service office locations |
| `office_schedules` | Per-day operating hours per office |
| `time_slots` | Pre-generated 30-min booking slots |
| `concern_types` | Bill clarification, account concern |
| `appointments` | All appointment records |
| `administrators` | Admin users with role-based access |
| `notifications` | SMS/email delivery tracking |
| `audit_logs` | Immutable action history |

## API Endpoints

### Consumer (No Auth)
| Method | Endpoint | Purpose |
|--------|----------|---------|
| POST | `/appointments` | Create appointment |
| GET | `/appointments/{ref}` | View by reference number |
| PUT | `/appointments/{ref}/reschedule` | Reschedule (verify via mobile) |
| PUT | `/appointments/{ref}/cancel` | Cancel (verify via mobile) |
| GET | `/offices` | List active offices |
| GET | `/concern-types` | List active concern types |
| GET | `/offices/{id}/slots?date=` | Available time slots |

## Key Design Decisions

1. **No consumer login** - Booking via reference number + mobile verification
2. **JWT stateless auth** for admin - No server-side sessions
3. **Pre-generated time slots** - Generated by cron, stored in DB for fast queries
4. **Database-level slot counting** - Triggers ensure atomicity
5. **Queue-based notifications** - Async delivery with retry mechanism
6. **JSONB audit logs** - Flexible entity version tracking
